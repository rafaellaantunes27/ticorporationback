# Evidências da prática
- `checks-local.txt`: resultados reproduzíveis de testes offline e checagem de critérios.
- `negative-test.txt`: controle negativo em arquivo temporário (sem modificar código versionado). **Não** equivale a rodada de subagente independente.
- Exigidos antes de marcar spec PRONTA: duas rodadas reais de subagente (`verificador-spec`) com tabelas, prova de reprovação por commit defeituoso, correção em commit posterior, teste integrado e evidências de operação feita pelo aluno.
- Não anexar chaves, senhas, tokens, logs com segredos, dados reais ou imagem de terceiros sem direitos.
